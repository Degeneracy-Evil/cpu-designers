## 第30章 位操作扩展

位操作（bitmanip）扩展集合由基础 RISC-V 架构的多个组件扩展组成，旨在提供代码大小缩减、性能提升和能耗降低的组合。虽然这些指令旨在通用，但某些指令在特定领域比其他领域更有用。因此，提供了多个较小的位操作扩展。每个较小的扩展按通用功能和使用场景分组，并各有自己的 Zb* 扩展名称。

每个位操作扩展包括一组具有相似目的且通常可共享相同逻辑的位操作指令。某些指令仅在一个扩展中可用，而其他指令在多个扩展中可用。这些指令具有独立于其所出现扩展的助记符和编码。因此，当实现具有重叠指令的扩展时，逻辑或编码不会冗余。

位操作扩展针对 RV32 和 RV64 定义。

位操作扩展遵循 RV64 中的约定：带 _w_ 后缀的指令（_w_ 前无点号）忽略其输入的高 32 位，对最低有效 32 位作为有符号值进行运算，并产生有符号扩展到 XLEN 的 32 位有符号结果。

带 _.uw_ 后缀的位操作指令有一个操作数是从指定寄存器的最低有效 32 位提取的无符号 32 位值。除此之外，这些指令执行完整的 XLEN 操作。

带 _.b_ 、_.h_ 和 _.w_ 后缀的位操作指令仅查看输入的最低有效 8 位、16 位和 32 位（分别），并根据具体指令产生有符号扩展或零扩展的 XLEN 宽结果。

位操作指令包含以下扩展：

- Zba：地址生成指令

- Zbb：基本位操作

- Zbs：单位指令

- Zbc：无进位乘法

- Zbkb：加密用位操作

- Zbkc：加密用无进位乘法

- Zbkx：交叉开关置换

xperm8 指令对字节进行操作。_rs1_ 寄存器包含 XLEN/8 个 8 位元素的向量。_rs2_ 寄存器包含 XLEN/8 个 8 位索引的向量。结果是 _rs2_ 中的每个元素被 _rs1_ 中索引到的元素替换，如果 _rs2_ 中的索引越界则为零。

```

    result : xlenbits = EXTZ(0b0);
foreach(i from0to xlen by8) {
        result[i+7..i] = xperm8_lookup(X(rs2)[i+7..i], X(rs1));
    };
    X(rd) = result;
    RETIRE_SUCCESS
}
```

## 30.9.51 zip

## 概要

将源寄存器的高半部分和低半部分分别交织到目标寄存器的奇数位和偶数位。

## 助记符

编码

## 描述

此指令将源字的高半部分和低半部分的位收集到目标字的奇/偶位位置。它是 unzip 指令的逆操作。此指令仅在 RV32 上可用。

## 操作

```

  X(rd)[2*i] = X(rs1)[i]
  X(rd)[2*i+1] = X(rs1)[i+xlen/2]
}
```

## **软件提示**

**此指令对于在 32 位架构上实现 SHA3 加密散列函数很有用，因为它直接实现了用于加速 64 位旋转的位交织操作。**
