## 第12章. "M" 整数乘除法扩展, 版本 2.0

本章描述标准整数乘除法指令扩展，命名为 `M`，包含对两个整数寄存器中保存的值进行乘法或除法运算的指令。

**评论：** _我们将整数乘除法从基础 ISA 中分离出来，以简化低端实现，或针对整数乘除法操作不频繁或更适合由附加加速器处理的场景。_

MUL 执行 XLEN 位 × XLEN 位的 `rs1` 乘以 `rs2` 乘法运算，并将低 XLEN 位结果放入目标寄存器。MULH、MULHU 和 MULHSU 执行相同的乘法，但返回完整 2×XLEN 位乘积的高 XLEN 位，分别对应有符号×有符号、无符号×无符号以及有符号 `rs1` ×无符号 `rs2` 乘法。如果需要同一乘积的高位和低位，推荐的代码序列为：`MULH[[S]U] rdh, rs1, rs2; MUL rdl, rs1, rs2`（源寄存器说明符必须保持相同顺序，且 `rdh` 不能与 `rs1` 或 `rs2` 相同）。微架构可以将这两条指令融合为单个乘法操作，而非执行两次独立的乘法。

**评论：** _MULHSU 用于多字有符号乘法中，将被乘数的最高有效字（包含符号位）与乘数的较低有效字（无符号）相乘。_

MULW 是 RV64 指令，将源寄存器的低 32 位相乘，并将结果的低 32 位符号扩展后放入目标寄存器。

**评论：** _在 RV64 中，可以使用 MUL 获取 64 位乘积的高 32 位，但有符号参数必须是适当的 32 位有符号值，而无符号参数的高 32 位必须清零。如果参数不保证是符号扩展或零扩展的，替代方案是将两个参数左移 32 位，然后使用 MULH[[S]U]。_

DIV 和 DIVU 执行 XLEN 位除以 XLEN 位的有符号和无符号整数除法，`rs1` 除以 `rs2`，向零舍入。REM 和 REMU 提供相应除法操作的余数。对于 REM，非零结果的符号等于被除数的符号。

**评论：** _对于有符号和无符号除法，除溢出情况外，恒有：被除数 = 除数 × 商 + 余数。_

如果需要同一除法的商和余数，推荐的代码序列为：`DIV[U] rdq, rs1, rs2; REM[U] rdr, rs1, rs2`（`rdq` 不能与 `rs1` 或 `rs2` 相同）。微架构可以将这两条指令融合为单个除法操作，而非执行两次独立的除法。

DIVW 和 DIVUW 是 RV64 指令，将 `rs1` 的低 32 位除以 `rs2` 的低 32 位，分别视为有符号和无符号整数，将 32 位商符号扩展到 64 位后放入 `rd`。REMW 和 REMUW 是 RV64 指令，提供相应的有符号和无符号余数操作。REMW 和 REMUW 始终将 32 位结果符号扩展到 64 位，包括除零的情况。

除零和除法溢出的语义总结于表 11。除零的商所有位全置 1，除零的余数等于被除数。有符号除法溢出仅在最大负整数除以 −1 时发生。溢出时有符号除法的商等于被除数，余数为零。无符号除法溢出不可能发生。

**评论：** _我们曾考虑在整数除零时引发异常，这些异常在大多数执行环境中会导致陷阱。然而，这将是标准 ISA 中唯一的算术陷阱（浮点异常设置标志并写入默认值，但不引发陷阱），并且会要求语言实现者为此情况与执行环境的陷阱处理器交互。此外，在语言标准要求除零异常必须引起立即控制流变更的情况下，只需在每次除法操作后添加一条分支指令，该分支指令可以插在除法之后，通常高度可预测为不跳转，几乎不增加运行时开销。_

**评论：** _无论无符号还是有符号除零，均返回全 1 的值，以简化除法器电路。全 1 的值既是无符号除法的自然返回值（表示最大无符号数），也是简单无符号除法器实现的自然结果。有符号除法通常使用无符号除法电路实现，指定相同的溢出结果简化了硬件。_

## 12.3. **`Zmmul`** 扩展, 版本 1.0

`Zmmul` 扩展实现了 M 扩展的乘法子集。它添加了第 12.1 节中定义的所有指令，即：MUL、MULH、MULHU、MULHSU 以及（仅 RV64）MULW。指令编码与对应的 M 扩展指令相同。`M` 隐含 `Zmmul`。

**评论：** _`Zmmul` 扩展使低成本实现成为可能，这些实现需要乘法操作但不需要除法。对于许多微控制器应用，除法操作过于罕见，不足以证明除法器硬件的成本是合理的。相比之下，乘法操作更加频繁，使得乘法器硬件的成本更可接受。简单的 FPGA 软核尤其受益于取消除法而保留乘法，因为许多 FPGA 提供硬连线乘法器，但要求除法器用软逻辑实现。_
