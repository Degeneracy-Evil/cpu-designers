# ALU控制信号快速参考

## One-Hot编码格式

控制信号为16位，每个操作对应一位，同一时间只有一位为1。

## 常用操作控制信号

### 算术运算

| 操作 | 十六进制 | 二进制 | 说明 |
| ---- | -------- | ------ | ---- |
| ADD  | 0x1000   | 0001_0000_0000_0000 | 加法 |
| SUB  | 0x0800   | 0000_1000_0000_0000 | 减法 |
| MUL  | 0x8000   | 1000_0000_0000_0000 | 乘法（32周期） |
| DIV  | 0x4000   | 0100_0000_0000_0000 | 除法（32周期） |

### 逻辑运算

| 操作 | 十六进制 | 二进制 | 说明 |
| ---- | -------- | ------ | ---- |
| AND  | 0x0100   | 0000_0001_0000_0000 | 按位与 |
| OR   | 0x0040   | 0000_0000_0100_0000 | 按位或 |
| XOR  | 0x0020   | 0000_0000_0010_0000 | 按位异或 |
| NOR  | 0x0080   | 0000_0000_1000_0000 | 按位或非 |
| NOT  | 0x2000   | 0010_0000_0000_0000 | 按位取反 |

### 移位运算

| 操作 | 十六进制 | 二进制 | 说明 |
| ---- | -------- | ------ | ---- |
| SLL  | 0x0010   | 0000_0000_0001_0000 | 逻辑左移 |
| SRL  | 0x0008   | 0000_0000_0000_1000 | 逻辑右移 |
| SRA  | 0x0004   | 0000_0000_0000_0100 | 算术右移 |

### 比较运算

| 操作 | 十六进制 | 二进制 | 说明 |
| ---- | -------- | ------ | ---- |
| SLT  | 0x0400   | 0000_0100_0000_0000 | 有符号小于 |
| SLTU | 0x0200   | 0000_0010_0000_0000 | 无符号小于 |

### 其他

| 操作 | 十六进制 | 二进制 | 说明 |
| ---- | -------- | ------ | ---- |
| LUI  | 0x0002   | 0000_0000_0000_0010 | 高位加载 |

## 测试用例

### 1. 加法: 12345 + 67890
```
控制信号: 0x1000
源操作数1: 0x00003039
源操作数2: 0x00010932
结果: 0x0001396B
```

### 2. 减法: 100 - 50
```
控制信号: 0x0800
源操作数1: 0x00000064
源操作数2: 0x00000032
结果: 0x00000032
```

### 3. 乘法: 123 × 456
```
控制信号: 0x8000
源操作数1: 0x0000007B
源操作数2: 0x000001C8
结果: 0x0000DB18
注意: 等待RVALD=1
```

### 4. 除法: 1000 ÷ 7
```
控制信号: 0x4000
源操作数1: 0x000003E8
源操作数2: 0x00000007
结果: 0x0000008E (142)
注意: 等待RVALD=1
```

### 5. 逻辑与: 0x12345678 & 0xF0F0F0F0
```
控制信号: 0x0100
源操作数1: 0x12345678
源操作数2: 0xF0F0F0F0
结果: 0x10305070
```

### 6. 左移: 0x0F << 4
```
控制信号: 0x0010
源操作数1: 0x00000004 (移位量)
源操作数2: 0x0000000F (被移位数)
结果: 0x000000F0
```

### 7. 有符号比较: -1 < 1
```
控制信号: 0x0400
源操作数1: 0xFFFFFFFF (-1)
源操作数2: 0x00000001 (1)
结果: 0x00000001 (真)
```

## 注意事项

1. **乘除法**: 需要等待result_valid信号（屏显RVALD），大约32个时钟周期
2. **移位**: src1[4:0]为移位量，src2为被移位数
3. **比较**: 结果为0或1
4. **复位**: 低电平有效，复位后所有寄存器清零
