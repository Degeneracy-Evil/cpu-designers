# 简单CPU

目标：实现一个支持RV32I中基础指令集的多周期的CPU，不具备中断、不连接主存，仅有算数指令、分支指令和跳转指令。

## 架构定义

CPU目前仅连接L1缓存，缓存部分使用哈佛架构，分为dcache和icache，这两个存储模块已经在rtl文件夹中。

## 指令定义

查看instruction-set.md中`3. RV32I 基础指令集`中3.1-3.7部分，总计40条指令。

## 模块定义

以下为六个子系统模块：
+ 取指：根据从icache中取指令
+ 解码：解析指令意义，解析指令类型，输出src1,src2
+ 执行：执行算数运算
+ 访存：向dcache请求数据
+ 回写：将结果写回寄存器堆
+ 控制器模块：负责按照状态机给每个模块使能信号。

### 解码

解码器输出包含两个方向：数据、微码

数据指传给执行单元的src1,src2，由解码器从立即数/寄存器中获取并输出。
微码指传给各个模块的控制信号，决定模块执行的功能，比如执行单元执行什么运算，访存是读还是写等等。

数据输出输出到总线，微码传递给控制器保持。

### 执行

执行模块内部ALU使用1-alu文件夹下的ALU，接口可见dev/1-alu/docs/ALU_INTERFACE.md

### 访存

原本使用BRAM IP核，模拟使用decache.v作为替代，已经放在rtl下，访存单元内部使用其作为RAM。

### 控制器

根据解码传递的数据，通过状态机描述执行通路，在某个模块应该执行的时候发送使能信号开启模块，以及发送对应微码确定模块功能。

注意执行器和访存需要多clk周期，此时使用握手信号判断是否完成。

## 模块间连接

模块间数据通过总线连接。

总线上模块间设置一组触发器作为输出缓存，以保证时序切换的时候数据的稳定。

### 模拟脚本

tools/mk.py是一个编译、执行脚本，使用其进行verilog模拟。

使用方法见tools/README-mk.md

### coe编译

需要coe文件（icache初始化文件，内部字符串描述指令流）或者tb需要指令的二进制码可以使用tools/rv2coe.py进行编译，支持riscv汇编和c语言（优先汇编，c语言部分功能未经过完全验证）。

使用方法见tools/README-rv2coe.md
