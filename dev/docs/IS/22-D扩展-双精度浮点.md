## 第22章. "D" 扩展：双精度浮点，版本 2.2

本章描述了标准双精度浮点指令集扩展，名为 "D"，增加了符合 IEEE 754-2008 算术标准的双精度浮点计算指令。D 扩展依赖于基本单精度指令子集 F。

## 22.1. D 寄存器状态

D 扩展将 32 个浮点寄存器 `f0-f31` 扩展到 64 位（Table 23 中 FLEN=64）。`f` 寄存器现在可以保存 32 位或 64 位浮点值，如下文第 22.2 节所述。

**评论：**_FLEN 可以是 32、64 或 128，具体取决于支持 F、D 和 Q 扩展中的哪些。最多可以支持四种不同的浮点精度，包括 H、F、D 和 Q。_

## 22.2. 较窄值的 NaN 装箱

当支持多种浮点精度时，较窄 _n_ 位类型（_n_ < FLEN）的有效值被表示在 FLEN 位 NaN 值的低 _n_ 位中，这一过程称为 NaN-boxing。有效的 NaN-boxed 值的上部位必须全为 1。因此，有效的 NaN-boxed _n_ 位值在作为任何更宽的 _m_ 位值（_n_ < _m_ ≤ FLEN）看待时表现为负静默 NaN（qNaN）。任何将较窄结果写入 'f' 寄存器的操作必须将最高的 FLEN-_n_ 位全部写入 1，以产生合法的 NaN-boxed 值。

**评论：**_软件可能不知道当前存储在浮点寄存器中的数据类型，但必须能够保存和恢复寄存器值，因此使用更宽操作传输较窄值的结果必须被定义。一个常见情况是被调用者保存的寄存器，但标准约定对于可变参数函数、用户级线程库、虚拟机迁移和调试等功能也是可取的。_

浮点 _n_ 位传输操作将 IEEE 标准格式的外部值移入和移出 `f` 寄存器，包括浮点加载和存储（FL_n_/FS_n_）以及浮点移动指令（FMV._n_.X/FMV.X._n_）。将较窄的 _n_ 位传输（_n_ < FLEN）移入 `f` 寄存器将创建有效的 NaN-boxed 值。从浮点寄存器进行较窄的 _n_ 位传输将传输寄存器的低 _n_ 位，忽略上部的 FLEN-_n_ 位。

除前一段描述的传输操作外，所有其他较窄 _n_ 位操作（_n_ < FLEN）的浮点操作都会检查输入操作数是否被正确 NaN-boxed，即所有上部的 FLEN-_n_ 位是否为 1。如果是，则输入的 _n_ 个最低有效位被用作输入值，否则输入值被视为 _n_ 位规范 NaN。

**评论：**_本文档的早期版本没有定义将较窄或较宽操作数的结果馈送到操作中的行为，除了要求较宽的保存和恢复将保留较窄操作数的值。新定义消除了这种特定于实现的行为，同时仍然适应浮点单元的非重编码和重编码实现。新定义还有助于通过在使用不正确的值时传播 NaN 来捕获软件错误。_

**评论：**_非重编码实现在每次浮点操作的输入和输出上解包和打包操作数为 IEEE 标准格式。对非重编码实现而言，NaN-boxing 的成本主要在于检查较窄操作的高位是否代表合法的 NaN-boxed 值，以及将结果的高位全部写入 1。_

## 22.5. 双精度浮点转换和移动指令
