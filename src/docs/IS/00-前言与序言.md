## _版本 2.0 前言_

这是用户 ISA 规范的第二次发布，我们希望用户基本 ISA 加上通用扩展（即 IMAFD）的规范在未来的开发中保持固定。自本 ISA 规范的版本 1.0 (Waterman et al., 2011) 以来，做出了以下变更。

- ISA 已被划分为一个整数基本 ISA 和若干个标准扩展。

- 指令格式已重新安排，以使立即数编码更高效。

- 基本 ISA 已定义为具有小端存储器系统，大端或双端作为非标准变体。

前言 | 第 12 页

- 加载保留/条件存储 ( `LR/SC` ) 指令已添加至原子指令扩展中。

- `AMO` 和 `LR/SC` 可以支持释放一致性模型。

- `FENCE` 指令提供更细粒度的存储器和 I/O 排序。

- 新增了用于获取并 `XOR` 的 `AMO` ( `AMOXOR` )，并更改了 `AMOSWAP` 的编码以腾出空间。

- `AUIPC` 指令将 20 位高位立即数加到 `PC` 上，替代了仅读取当前 `PC` 值的 `RDNPC` 指令。这为位置无关代码带来了显著的节省。

- `JAL` 指令现已移至 `U 型` 格式，带有显式目标寄存器，而 `J` 指令已被废弃，由 _rd_ = `x0` 的 `JAL` 替代。这移除了唯一带有隐式目标寄存器的指令，并从基本 ISA 中移除了 `J 型` 指令格式。这伴随着 `JAL` 跳转范围的减小，但显著降低了基本 ISA 的复杂性。

- `JALR` 指令上的静态提示已被移除。对于符合标准调用约定的代码，这些提示与 _rd_ 和 _rs1_ 寄存器指定符功能重复。

- `JALR` 指令现在清除计算出的目标地址的最低位，以简化硬件并允许在函数指针中存储辅助信息。

- `MFTX.S` 和 `MFTX.D` 指令已分别重命名为 `FMV.X.S` 和 `FMV.X.D`。类似地，`MXTF.S` 和 `MXTF.D` 指令已分别重命名为 `FMV.S.X` 和 `FMV.D.X`。

- `MFFSR` 和 `MTFSR` 指令已分别重命名为 `FRCSR` 和 `FSCSR`。新增了 `FRRM`、`FSRM`、`FRFLAGS` 和 `FSFLAGS` 指令，以单独访问 `fcsr` 的舍入模式和异常标志子字段。

- `FMV.X.S` 和 `FMV.X.D` 指令现在从 _rs1_ 而不是 _rs2_ 获取它们的操作数。此更改简化了数据通路设计。

- 新增了 `FCLASS.S` 和 `FCLASS.D` 浮点分类指令。

- 采用了更简单的 NaN 生成和传播方案。

- 对于 `RV32I`，系统性能计数器已扩展为 64 位宽，可分别读取高 32 位和低 32 位。

- 定义了规范 `NOP` 和 `MV` 编码。

- 已为 48 位、64 位和 >64 位指令定义了标准指令长度编码。

- 新增了对 128 位地址空间变体 `RV128` 的描述。

- 32 位基本指令格式中的主要操作码已分配给用户定义的自定义扩展。

- 纠正了一处排版错误，该错误暗示存储指令从 _rd_ 获取其数据，现已更正为指代 _rs2_。
