# UART 说明文档

## 1. 模块概述
**通用异步收发传输器（UART）** 是一种用于在串行通信与并行通信之间进行数据转换的硬件电路。

## 2. 接口信号

### 输入信号

| 名称   | 长度   | 含义       |
| ------ | ------ | ---------- |
| clk    | 1 位   | 时钟信号   |
| rstn   | 1 位   | 置零信号   |
| we_i   | 1 位   | 写使能     |
| addr_i | 32 位  | 写入地址   |
| data_i | 32 位  | 写入数据   |
| rx_pin | 1 位   | 接收数据端 |

### 输出信号

| 名称   | 长度   | 含义       |
| ------ | ------ | ---------- |
| data_o | 32 位  | 输出数据   |
| tx_pin | 1 位   | 发生数据端 |

## 3. 寄存器定义
UART 模块包含以下四个主要寄存器，用于控制和监控通信状态。

| 寄存器名称 | 读写权限 | 功能描述 |
| :--- | :--- | :--- |
| **uart_ctrl** | R/W | 控制寄存器，用于使能 TX 和 RX 功能 |
| **uart_status** | R/W (混合) | 状态寄存器，反馈 TX/RX 的忙闲及完成状态 |
| **uart_tx** | R/W | 发送数据寄存器，存放待发送的数据 |
| **uart_rx** | RO | 接收数据寄存器，只读，存放接收到的数据 |

**寄存器详细位定义：**

*   **uart_ctrl (控制寄存器)**
    *   `bit[0]`: UART TX 使能 (1: enable, 0: disable)
    *   `bit[1]`: UART RX 使能 (1: enable, 0: disable)
    *   *注：寄存器值从 mesh 传入，仅取低八位，高 24 位置零。*

*   **uart_status (状态寄存器)**
    *   `bit[0]` (RO): TX 空闲状态标志 (1: busy, 0: idle)
    *   `bit[1]` (R/W): RX 接收完成标志 (1: over, 0: receiving)

## 4. 功能实现逻辑

**接收数据 (RX)**
1.  调用 `uart_rx` 模块，将外界数据传入 `rx_data`。
2.  当外界数据发送完毕，拉高 `rx_data_valid` 信号。
3.  模块检测到有效信号后，将 `rx_recv_over` 置为 1，提示接收完成。
4.  数据写入寄存器 `uart_rx`。

**发送数据 (TX)**
1.  **触发条件**：需同时满足以下三点：
    *   输出使能为 1 (`write_reg_txdata_en`)
    *   UART TX 空闲 (`uart_status[0] == 0`)
    *   数据准备就绪 (`tx_data_ready`)
2.  允许将 Mesh 网上传来的数据 (`data_i`) 输出到寄存器 `uart_tx`。
3.  调用 `uart_tx` 模块，将数据发送到外界。
4.  数据准备好后拉高 `tx_data_ready` 开始传出。

**状态更新机制**
*   **接收完成**：当接收完数据后，将 `uart_status[1]` 写入 1。
*   **发送状态**：
    *   开始发送时 (`tx_start=1`)，将 `uart_status[0]` 写入 1 (Busy)。
    *   发送完成后，将 `uart_status[0]` 写入 0 (Idle)。
