在使用bootloader前请确保安装了python和必要的串口依赖，依赖安装命令：
`pip install pyserial`
使用串口转换线(FT232，龙芯实验箱自带)与串口连接线，将实验箱上的串口与电脑的USB端口连接。从设备管理器中查看串口编号。
 
在bootloader文件夹下打开命令提示行，执行以下命令：
Python main.py COMX bin_file_name
其中COMX为串口编号，bin_file_name为需要烧录的二进制文件名。

程序会读取二进制文件bin_file_name.data.bin和bin_file_name.inst.bin
 
注意，每次烧录前请按下FPGA的复位按钮，确保FPGA处于复位状态。
