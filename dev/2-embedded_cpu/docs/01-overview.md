# 01 - 项目概述

## 1. 项目背景

本项目是计算机组成原理课程实验二，目标是在 FPGA 平台上实现一个 **32 bit RISC-V 多周期 CPU**。采用哈佛结构，基于已有 ALU 完成 CPU 系统集成。

## 2. 总体目标

1. 设计并实现一个 **32 bit RISC-V 多周期 CPU**
2. 实现完整 **RV32I + Zicsr** 指令集（共 47 条指令）
3. 运算功能基于 `dev/1-alu` 中 ALU，不使用外部 IP 核
4. 采用 **哈佛结构**，指令存储与数据存储分离
5. 实现精简异常处理与一级中断机制
6. 支持 **GPIO** 与 **UART** 外设（MMIO 方式）
7. 优先实现 UART 接收中断

## 3. 设计边界

以下为硬性约束，不得突破：

| 约束 | 说明 |
|------|------|
| 不实现流水线 | CPU 必须为多周期结构 |
| 不实现多级中断 | 仅单级 trap 控制；默认只响应外部中断（MEIP），不实现可编程优先级/中断嵌套 |
| 仅实现 RV32I + Zicsr | 不实现 M/A/F/D/C 扩展 |
| 不实现 MMU/虚拟内存 | 无页表、无地址翻译 |
| 不实现 S-mode | 仅 M-mode + U-mode |
| 不实现定时器中断 | 暂不实现 Machine timer interrupt |
| 仅 iverilog 验证 | 仿真使用 Icarus Verilog，Vivado 迁移由人工完成 |
| 统一构建入口 | 所有编译/运行/回归命令统一通过仓库根目录 `mk.py` 执行 |
