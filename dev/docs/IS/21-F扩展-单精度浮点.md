## 第21章. "F" 扩展：单精度浮点，版本 2.2

本章描述了单精度浮点的标准指令集扩展，名为 "F"，增加了符合 IEEE 754-2008 算术标准的单精度浮点计算指令 [citation]( _ANSI/IEEE Std 754-2008, IEEE Standard for Floating-Point Arithmetic_ , 2008)。F 扩展依赖于 "Zicsr" 扩展以访问控制与状态寄存器。

## 21.1. F 寄存器状态

F 扩展增加了 32 个浮点寄存器，`f0-f31`，每个 32 位宽，以及一个浮点控制与状态寄存器 `fcsr`，其中包含浮点单元的操作模式和异常状态。此附加状态如 Table 23 所示。我们使用术语 FLEN 来描述 RISC-V ISA 中浮点寄存器的宽度，对于 F 单精度浮点扩展，FLEN=32。大多数浮点指令对浮点寄存器文件中的值进行操作。浮点加载和存储指令在寄存器和内存之间传输浮点值。还提供了在整数寄存器文件和浮点寄存器文件之间传输值的指令。

_我们考虑过为整数和浮点值采用统一的寄存器文件，因为这简化了软件寄存器分配和调用约定，并减少了总体用户状态。然而，分离的组织方式在给定指令宽度下增加了可访问的寄存器总数，简化了为宽超标量发射提供足够寄存器文件端口，支持解耦的浮点单元架构，并简化了内部浮点编码技术的使用。编译器支持和分离寄存器文件架构的调用约定已经很成熟，并且对浮点寄存器文件状态使用脏位可以减少上下文切换开销。_

`fcsr` 寄存器可以通过 FRCSR 和 FSCSR 指令读取和写入，这些指令是基于底层 CSR 访问指令的汇编伪指令。FRCSR 读取 `fcsr` 并将其复制到整数寄存器 _rd_ 中。FSCSR 交换 `fcsr` 中的值，将原始值复制到整数寄存器 _rd_ 中，然后将从整数寄存器 _rs1_ 获取的新值写入 `fcsr`。

`fcsr` 中的字段也可以通过不同的 CSR 地址单独访问，并为这些访问定义了单独的汇编伪指令。FRRM 指令读取舍入模式字段 `frm`（`fcsr` 第 7—5 位），并将其复制到整数寄存器 _rd_ 的最低三位，其余位为零。FSRM 交换 `frm` 中的值，将原始值复制到整数寄存器 _rd_ 中，然后将从整数寄存器 _rs1_ 的最低三位获取的新值写入 `frm`。FRFLAGS 和 FSFLAGS 对累积异常标志字段 `fflags`（`fcsr` 第 4—0 位）的定义类似。

`fcsr` 的第 31—8 位保留用于其他标准扩展。如果未实现这些扩展，实现应忽略对这些位的写入，并在读取时提供零值。标准软件应保留这些位的内容。

规范 NaN 具有正号位，且所有尾数位除 MSB（静默位）外均为零。对于单精度浮点，这对应于模式 `0x7fc00000`。

**评论：**_我们考虑过按照标准建议传播 NaN 的有效载荷（payload），但这一决定会增加硬件成本。此外，由于此功能在标准中是可选的，因此不能在可移植代码中使用。_

**评论：**_实现者可以自由地将 NaN 有效载荷传播方案作为由非标准操作模式启用的非标准扩展提供。然而，上述规范 NaN 方案必须始终受支持，并应为默认模式。_

**评论：**_我们要求实现在异常条件下返回标准规定的默认值，而不需要用户级软件的任何进一步干预（不同于 Alpha ISA 的浮点陷阱屏障）。我们相信完全硬件处理异常情况将变得更加普遍，因此希望避免为了优化其他方法而使 ISA 复杂化。实现始终可以通过陷阱进入机器模式软件处理程序来提供异常的默认值。_

## 21.7. 单精度浮点转换和移动指令

浮点到整数和整数到浮点的转换指令在 OP-FP 主操作码空间中编码。FCVT.W.S 或 FCVT.L.S 分别将浮点寄存器 _rs1_ 中的浮点数转换为整数寄存器 _rd_ 中的有符号 32 位或 64 位整数。FCVT.S.W 或 FCVT.S.L 分别将整数寄存器 _rs1_ 中的 32 位或 64 位有符号整数转换为浮点寄存器 _rd_ 中的浮点数。FCVT.WU.S、FCVT.LU.S、FCVT.S.WU 和 FCVT.S.LU 变体用于转换自/至无符号整数值。对于 XLEN>32，FCVT.W[U].S 将 32 位结果符号扩展到目标寄存器宽度。FCVT.L[U].S 和 FCVT.S.L[U] 是 RV64 专用指令。如果舍入结果在目标格式中不可表示，则将其截断为最近值并设置无效标志。Table 27 给出了 FCVT._int_.S 的有效输入范围及对无效输入的行为。

## 21.8. 单精度浮点比较指令

浮点比较指令（FEQ.S、FLT.S、FLE.S）在浮点寄存器之间执行指定的比较（_rs1_ = _rs2_、_rs1_ < _rs2_、_rs1_ ≤ _rs2_），如果条件成立则将 1 写入整数寄存器 _rd_，否则写入 0。

FLT.S 和 FLE.S 执行 IEEE 754-2008 标准所称的 _signaling_ 比较：即，如果任一输入是 NaN，它们会设置无效操作异常标志。FEQ.S 执行 _quiet_ 比较：它仅在任一输入是信号 NaN 时设置无效操作异常标志。对于这三条指令，如果任一操作数是 NaN，结果都是 0。
