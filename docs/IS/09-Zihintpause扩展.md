# 第9章 "Zihintpause" 暂停提示扩展，版本 2.0

PAUSE 指令是一个 HINT，指示当前硬件线程的指令退休速率应暂时降低或暂停。其效果的持续时间必须是有界的，且可以为零。

_软件可以使用 PAUSE 指令在执行自旋等待代码序列时降低能耗。多线程核心可以在执行 PAUSE 时暂时将执行资源让给其他硬件线程。建议在自旋等待循环的代码序列中通常包含一条 PAUSE 指令。_

_PAUSE 指令效果的持续时间在不同的实现之间以及同一实现内部可能有显著差异。在典型实现中，该持续时间应远小于执行上下文切换的时间，可能大致处于片上缓存未命中延迟或对主存的无缓存访问的数量级。_

_一系列 PAUSE 指令可用于创建与 PAUSE 指令数量大致成比例的累积延迟。然而，在可移植代码的自旋等待循环中，在重新评估循环条件之前只应使用一条 PAUSE 指令，否则硬件线程在某些实现上可能停顿过久而降低系统性能。_

PAUSE 编码为一条 FENCE 指令，其中 _pred_ = `W`，_succ_ = `0`，_fm_ = `0`，_rd_ = `x0`，_rs1_ = `x0`。

_PAUSE 编码为 FENCE 操作码内的一个提示，因为某些实现预期会故意将 PAUSE 指令停顿到未完成的内存事务完成为止。然而，由于后继集是空的，PAUSE 并不强制任何特定的内存排序——因此，它确实是一个 HINT。_

_与其他 FENCE 指令一样，PAUSE 不能在 LR/SC 序列中使用而不会作废前向进度保证。_

_鉴于后继集为空，选择 W 作为前驱集是任意的。类似 PAUSE 的其他 HINT 可能以其他前驱集编码。_
