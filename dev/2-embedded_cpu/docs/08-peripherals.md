# 08 - 外设设计

## 1. GPIO

### 1.1 功能

- 基本输入与输出
- 优先作为系统早期调试接口
- 可连接 LED、拨码开关、按键等板级资源

### 1.2 接口

| 信号 | 位宽 | 方向 | 描述 |
|------|------|------|------|
| gpio_in | 32 | input | 外部输入（开关/按键） |
| gpio_out | 32 | output | 外部输出（LED） |

### 1.3 寄存器

详见 `06-memory-mapping.md` 第 3.2 节。

## 2. UART

### 2.1 功能

- 基本收发能力
- 作为上位机—下位机调试的主要接口
- 接收路径与中断机制联动

### 2.2 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 波特率 | 可配置 | 默认 115200 |
| 数据位 | 8 | |
| 停止位 | 1 | |
| 校验 | 无 | |

### 2.3 接口

| 信号 | 位宽 | 方向 | 描述 |
|------|------|------|------|
| uart_tx | 1 | output | 发送线 |
| uart_rx | 1 | input | 接收线 |
| uart_irq | 1 | output | 接收中断请求 |

### 2.4 寄存器

详见 `06-memory-mapping.md` 第 3.3 节。

### 2.5 发送流程

1. CPU 写入 uart_tx 寄存器
2. UART 模块按波特率逐位发送
3. 发送完成前 uart_status[0] = 1（TX busy）
4. 发送完成后 uart_status[0] = 0

### 2.6 接收流程

1. UART 模块检测 uart_rx 线上的起始位
2. 按波特率采样接收数据位
3. 接收完成后写入接收缓冲区，uart_status[1] = 1（RX ready）
4. 若 uart_ctrl[0] = 1（RX interrupt enable），置 mip.MEIP = 1
5. CPU 读取 uart_rx 寄存器后，清除 RX ready 标志
