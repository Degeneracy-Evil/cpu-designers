#### 乘法指令

- **`mul rd, rs1, rs2`**
    - **功能**: 乘法。
    - **描述**: $x[rd] = x[rs1] \times x[rs2]$。将 `rs2` 与 `rs1` 相乘，乘积写入 `rd`。忽略算术溢出。
    - **类型**: R 型，在 RV32M 和 RV64M 中。
    - **指令格式**:

#### 除法指令
