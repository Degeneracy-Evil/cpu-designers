# Bus4LZU系统总线控制器技术文档

## 1. 概述

Bus4LZU是一个集成化的系统总线控制器IP核，专为嵌入式系统设计，集成了内存管理、外设控制和系统初始化功能。它作为CPU核心与外部设备之间的桥梁，提供完整的系统解决方案。

## 2. 主要功能

### 2.1 系统初始化与程序加载

- **CPU暂停控制**：通过`init_sig`信号在初始化期间暂停CPU运行
- **串口程序加载**：通过UART接口接收外部数据包
- **智能数据分流**：根据包头识别数据类型，自动分流至Icache或Dcache
- **数据校验机制**：支持Checksum校验，确保数据完整性
- **通信反馈**：校验通过发送ACK，失败发送NAK

### 2.2 地址解码与内存管理

- **地址空间划分**：
    - `0x0000 - 0xFFFF`：映射到SRAM（缓存）
    - `0x10000及以上`：映射到外设
- **读写时序管理**：
    - 读操作：1个时钟周期延迟
    - 写操作：无延迟

### 2.3 外设控制模块

**UART串口通信**

- 波特率：固定115200
- 功能：与外部设备进行串行通信

**GPIO通用输入输出**

- 可配置引脚数量：1-16位
- 输入模式：监测外部电平状态
- 输出模式：控制外部设备

**定时器(TIMER)**

- 功能：时钟计数
- 中断支持：计数达到设定值时触发`timer_iqr`中断

**SPI通信接口**

- 支持SPI从机设备通信
- 可配置时钟极性、相位和分频

## 3. 硬件接口定义

### 3.1 系统控制接口

| 信号名 | 方向 | 描述 |
| ------ |------ |------ |
| `clk` | 输入 | 系统时钟 |
| `rst` | 输入 | 系统复位 |
| `init_sig` | 输出 | 初始化信号，用于暂停CPU |

### 3.2 CPU总线接口

| 信号名 | 方向 | 描述 |
| ------ |------ |------ |
| `addr` | 输出 | 地址总线 |
| `data` | 双向 | 数据总线 |
| `rd_en` | 输出 | 读使能 |
| `wr_en` | 输出 | 写使能 |

### 3.3 外设接口

**GPIO接口**

- `gpio_io[N-1:0]`：双向数据接口，位宽由`gpio_num`参数决定

**UART接口**

- `uart_rx`：串行接收
- `uart_tx`：串行发送

**中断接口**

- `timer_iqr`：定时器中断请求

## 4. 配置参数

### 4.1 可配置参数

| 参数名 | 范围 | 默认值 | 描述 |
| ------ |------ |------ |------ |
| `clk_freq` | 1-100 | 25 | 系统时钟频率(MHz) |
| `gpio_num` | 1-16 | 16 | GPIO引脚数量 |

### 4.2 配置方法

在Vivado的"Customize IP"界面中进行参数设置：

1. 找到`clk_freq`参数，输入实际时钟频率值
2. 设置`gpio_num`为需要的引脚数量
3. 确认配置并生成IP核

## 5. 使用方法

### 5.1 系统启动流程

1. **上电复位**：系统复位后，Bus4LZU拉高`init_sig`暂停CPU
2. **程序加载**：通过UART接收程序数据包
3. **数据校验**：对每个数据包进行Checksum校验
4. **内存初始化**：将校验通过的数据写入Icache/Dcache
5. **启动CPU**：加载完成后拉低`init_sig`，CPU从0x0000地址开始执行

## 6. 注意要点

### 6.1 硬件设计注意事项

1. **时钟同步**：确保CPU核心与Bus4LZU使用相同的时钟源
2. **复位同步**：CPU复位信号应与系统复位同步
3. **引脚匹配**：顶层模块例化时，GPIO位宽必须与`gpio_num`配置一致
4. **地址对齐**：CPU访问外设时，地址必须符合地址空间划分规则

### 6.2 软件开发注意事项

1. **驱动兼容性**：修改`gpio_num`参数后必须重新编译软件驱动
2. **中断优先级**：合理配置中断优先级，避免关键中断被阻塞
3. **内存访问**：避免访问未映射的地址空间，防止系统异常
4. **时钟配置**：准确配置`clk_freq`参数，确保波特率等计算正确

### 6.3 资源优化建议

1. **GPIO数量**：根据实际需求配置`gpio_num`，避免资源浪费
2. **时钟频率**：选择合适的时钟频率，在性能和功耗间取得平衡
3. **中断使用**：合理使用中断，避免过度中断导致CPU负载过高

## 8. 常见问题解答

### 8.1 Q: 为什么需要配置`clk_freq`参数？

A: 该参数用于内部时序计算，如UART波特率生成器需要根据系统时钟进行分频。

### 8.2 Q: 修改`gpio_num`后软件需要做什么调整？

A: 需要重新编译BSP驱动，并确保软件中GPIO操作的位宽与硬件配置一致。

### 8.3 Q: 系统启动时CPU为什么会被暂停？

A: 为了防止CPU在程序加载完成前访问空的内存区域，确保系统稳定启动。
